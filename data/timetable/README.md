# 지하철 열차 시간표 (당일 분실 화면용)

당일 분실 화면에서 **내린 역·내린 시각·방향으로 "탔던 열차"를 계산**할 때 쓰는 시간표예요. (#서유석 수정 6차)

- 원본: 서울교통공사_서울 도시철도 열차운행시각표_20260901 (공공데이터포털 15098251, CSV)
  - https://www.data.go.kr/data/15098251/fileData.do · 로그인 없이 다운로드 · 이용허락범위 제한 없음 · 무료
  - 1~9호선 전체 역 (1호선은 코레일 구간 포함 102개 역)
- 인증키가 필요 없고 호출 한도도 없어요. 화면이 노선·요일에 맞는 파일 하나만 받아요 (50~280KB).

## 파일

| 파일 | 내용 |
|---|---|
| `index.json` | 노선·요일별 파일 이름, 실시간 열차 방향(updnLine 0/1)과 시간표 방향 대응, 열차번호를 바로 맞출 수 있는 노선 |
| `{호선}_{DAY·SAT·END}.json` | DAY 평일, SAT 토요일, END 일요일·공휴일. 토요일이 휴일과 같으면 `index.json`이 휴일 파일을 가리켜요 |
| `make_timetable.py` | 새 CSV가 올라오면 다시 만드는 스크립트 |

`{호선}_{요일}.json` 형식

```
st: 역 이름 목록
tr: [열차코드, 방향(UP·DOWN·IN·OUT), 급행(1/0), 도착역, [역번호, 시각, 역번호, 시각, ...]]
시각: 0시부터 분×10 (예: 11:10:30 → 6705). 영업일 기준이라 밤 12시가 넘으면 1440분 이상
```

## 화면에서 쓰는 방법 (index.html `subwayView`)

1. 내린 날의 요일(평일·토요일·일요일/공휴일)로 파일을 고르고, 내린 역에 **내린 시각 앞뒤 8분 안에** 같은 방향으로 선 열차를 찾아요 → "탔던 열차 후보" (시각이 가장 가까운 열차가 1순위)
2. 후보 열차가 지금 어디 있는지
   - 실시간 열차번호가 시간표 열차코드와 같은 노선(1·3~9호선)은 **열차번호로 바로 맞춰** 실시간 위치를 보여 줘요
   - 2호선 본선은 실시간 번호 체계가 달라서, 시간표로 계산한 지금 위치에서 가장 가까운 실시간 열차를 보여 줘요
   - 실시간에 없으면 시간표상 지금 위치를 보여 주고, 이미 종점에 닿았으면 종착 시각과 역을 알려 줘요
3. 시간표가 없는 노선(경의중앙선·수인분당선·신분당선·신림선·우이신설선)은 내린 지 지난 시간 ÷ 평균 2분으로 추정해요

## 확인한 내용 (2026-11-10 오전, 실시간 열차 400대와 대조)

- 1·3~9호선: 실시간 열차번호의 숫자 = 시간표 열차코드의 숫자 (시간표 코드는 앞뒤에 K·S·C 같은 글자가 붙음), 같은 역의 시각 차이 중앙값 1~5분
- 2호선 본선: 번호 체계가 달라 시각으로 맞춤 (지선은 번호가 같음)
- 방향: 실시간 updnLine 0 = 시간표 UP(2호선 본선은 OUT, 9호선은 DOWN)

## 다시 만들기

```
python make_timetable.py 서울교통공사_서울도시철도열차운행시각표_YYYYMMDD.csv
```
